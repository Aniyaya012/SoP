# WVS Wave 7 智能体特征字段说明

## 用途与来源

本文档解释地铁化学袭击场景中每名智能体档案的 19 个 WVS Wave 7 特征。它面向两类读者：检查智能体信息的人，以及需要理解档案字段的 LLM。

字段来自 World Values Survey, Round Seven, Country-Pooled Datafile Version 6.0。字段标题、离散回答标签和指数方向依据 WVS Wave 7 官方在线分析与代码簿文档核对。官方文档入口：<https://www.worldvaluessurvey.org/WVSDocumentationWV7.jsp>。

本项目使用的是 WVS 数值字段，不会据此虚构职业、具体住址、家庭角色、社会关系或个人经历。

## 档案中的三类数值

每条 `profiles.jsonl` 档案包含以下相关字段：

```json
{
  "raw_features": {"Q273": 1, "Q274": 2, "Q57": 2},
  "feature_response_status": {
    "Q273": "observed",
    "Q274": "observed",
    "Q57": "observed"
  },
  "standardized_features": {"Q273": -0.77, "Q274": 0.18, "Q57": 0.56}
}
```

| 字段 | 含义 | 使用时的解释 |
| --- | --- | --- |
| `raw_features` | 清洗后的 WVS 原始数值回答 | 离散变量必须按本文的编码表解释；连续变量按量表和方向解释。 |
| `feature_response_status` | 回答是否是实际观察值 | `observed` 表示原始回答可用；`missing_or_special_code` 表示原始缺失或特殊编码已被数值清洗为 `0`。 |
| `standardized_features` | 相对完整 WVS 清洗样本的 z-score | `z = (清洗后取值 - WVS 总体均值) / WVS 总体标准差`。`0` 表示接近总体均值，正值高于总体均值，负值低于总体均值。 |

### 必须注意的规则

1. `raw_features` 中的 `0` 不总是同一种意思。`Q274=0` 且状态为 `observed` 表示“没有子女”；若状态为 `missing_or_special_code`，则表示原始回答缺失或特殊编码，不能解释为“没有子女”。
2. 除 `Y003` 的 `-2` 和 `-1` 外，负的 WVS 特殊编码会被清洗为 `0`。`Y003=-2` 至 `2` 是有效的自主性指数取值，予以保留。
3. 对性别、婚姻状态、区域代码等名义变量，z-score 只是数值模块为了统一输入而生成的数学变换，不表示“更高”或“更低”的社会属性。LLM 不应根据名义变量的 z-score 推断偏好。
4. `N_REGION_WVS` 是国家内部的地区编码，不是跨国统一的社会尺度。它不能仅凭数值推断地区特征；当前决策提示词不向 LLM 提供该字段。

## 19 个字段总览

| 键名 | 中文名称 | WVS 官方含义 | 类型 | 应如何理解 |
| --- | --- | --- | --- | --- |

| `Q260` | 性别 | Sex | 名义离散 | 男性或女性。 |
| `Q273` | 婚姻状态 | Marital status | 名义离散 | 已婚、同居、离异等。 |
| `Q274` | 子女数量 | How many children do you have | 计数 | 已报告子女数。 |
| `Q275` | 最高教育程度 | Highest educational level: Respondent [ISCED 2011] | 有序离散 | 依照 ISCED 2011 教育层级。 |
| `N_REGION_WVS` | 国家特定 WVS 地区 | Region country specific | 国家内分类代码 | 仅用于复现和数值模块，不能跨国解释。 |
| `G_TOWNSIZE` | 聚落规模 | Settlement size, 8 groups | 有序离散 | 居住地人口规模区间。 |
| `Q3` | 闲暇时间重要性 | Important in life: Leisure time | 有序离散 | 闲暇时间在生活中的重要程度。 |
| `Q46` | 主观幸福感 | Feeling of happiness | 有序离散 | 总体幸福感自我评价。 |
| `Q55` | 安全住所匮乏 | Gone without a safe shelter over your head | 有序离散 | 过去 12 个月缺乏安全住所的频率。 |
| `Q57` | 一般社会信任 | Most people can be trusted | 二元离散 | 信任大多数人，或认为与人交往需谨慎。 |
| `Y003` | 自主性指数 | Autonomy Index | 连续指数 | `-2` 至 `2`；低值偏服从/宗教信仰，高值偏独立/坚毅。 |
| `I_AUTHORITY` | 反向权威尊重 | Inverse respect for authority | 连续指数 | 值越高，越少尊重权威。 |

| `SCEPTICISM` | 怀疑性 | Scepticism index | 连续指数 | 值越高，怀疑性越强。 |
| `AUTONOMY` | 自主性 | Autonomy sub-index | 连续指数 | 值越高，自主性越强。 |
| `EQUALITY` | 平等取向 | Equality sub-index | 连续指数 | 值越高，平等取向越强。 |
| `I_DEVOUT` | 反向宗教虔诚度 | Inverse devoutness | 连续指数 | 值越高，宗教虔诚度越低。 |

## 离散字段：编码和值的含义

### `X003R`：年龄组

| 原始值 | 含义 |
| ---: | --- |
| `1` | 16-24 岁 |
| `2` | 25-34 岁 |
| `3` | 35-44 岁 |
| `4` | 45-54 岁 |
| `5` | 55-64 岁 |
| `6` | 65 岁及以上 |

### `Q260`：性别

| 原始值 | 含义 |
| ---: | --- |
| `1` | 男性 |
| `2` | 女性 |

### `Q273`：婚姻状态

| 原始值 | 含义 |
| ---: | --- |
| `1` | 已婚 |
| `2` | 与伴侣同居，如同已婚 |
| `3` | 离婚 |
| `4` | 分居 |
| `5` | 丧偶 |
| `6` | 单身 |

### `Q274`：子女数量

该变量是计数，不是等级代码。

| 原始值 | 含义 |
| ---: | --- |
| `0` 且状态为 `observed` | 没有子女 |
| `1` | 1 名子女 |
| `2` | 2 名子女 |
| `3` 及以上 | 对应数量的子女；源数据保留实际报告数，不应人为截断为 7。 |
| `0` 且状态为 `missing_or_special_code` | 原始回答缺失或特殊编码，不能解释为没有子女。 |

### `Q275`：最高教育程度（ISCED 2011）

| 原始值 | 含义 |
| ---: | --- |
| `0` | 学前教育（ISCED 0）或未受教育 |
| `1` | 小学教育（ISCED 1） |
| `2` | 初中教育（ISCED 2） |
| `3` | 高中教育（ISCED 3） |
| `4` | 中等后非高等教育（ISCED 4） |
| `5` | 短周期高等教育（ISCED 5） |
| `6` | 学士或同等学历（ISCED 6） |
| `7` | 硕士或同等学历（ISCED 7） |
| `8` | 博士或同等学历（ISCED 8） |

### `N_REGION_WVS`：国家特定 WVS 地区

该字段的值是与国家相绑定的地区标识符。例如，不同国家的地区编码体系不同，数值大小不代表人口规模、发展水平、城市化程度或价值观强弱。因此：

- 它可以保留在数值数据中，用于复现实验或研究地理异质性；
- 它不能作为一个可直接解释的“连续特征”；
- 未提供相应国家的地区代码簿时，不能向 LLM 只发送数字并期待其理解；
- 当前 LLM 决策提示词排除它。

### `G_TOWNSIZE`：聚落规模

| 原始值 | 含义 |
| ---: | --- |
| `1` | 少于 2,000 人 |
| `2` | 2,000-5,000 人 |
| `3` | 5,000-10,000 人 |
| `4` | 10,000-20,000 人 |
| `5` | 20,000-50,000 人 |
| `6` | 50,000-100,000 人 |
| `7` | 100,000-500,000 人 |
| `8` | 500,000 人及以上 |

### `Q3`：闲暇时间重要性

题意：闲暇时间在你的生活中有多重要？

| 原始值 | 含义 |
| ---: | --- |
| `1` | 非常重要 |
| `2` | 比较重要 |
| `3` | 不太重要 |
| `4` | 完全不重要 |

### `Q46`：主观幸福感

题意：综合来看，你会说自己是？

| 原始值 | 含义 |
| ---: | --- |
| `1` | 非常幸福 |
| `2` | 比较幸福 |
| `3` | 不太幸福 |
| `4` | 完全不幸福 |

### `Q55`：安全住所匮乏

题意：在过去 12 个月中，你或你的家人缺乏安全住所的频率是？

| 原始值 | 含义 |
| ---: | --- |
| `1` | 经常 |
| `2` | 有时 |
| `3` | 很少 |
| `4` | 从不 |

数值越小代表安全住所匮乏发生得越频繁，但清洗后的 `0` 不能被解释为“比经常更频繁”。

### `Q57`：一般社会信任

题意：一般来说，大多数人可以信任，还是与人交往需要非常谨慎？

| 原始值 | 含义 |
| ---: | --- |
| `1` | 大多数人可以信任 |
| `2` | 与人交往需要非常谨慎 |

这不是“社交活跃程度”，也不能将 `2` 解读为比 `1` 更高或更低的连续水平。

## 连续价值指数：数值和方向

以下字段是由 WVS 题项组合得到的指数，不是单一道问卷题目的离散选项。应同时阅读原始值、量程、方向和 z-score。除 `Y003` 外，这些指数在本数据中通常落在 `0` 至 `1` 的区间；精确取值可为小数。

| 键名 | 原始量程 | 值更高时表示 | 解释限制 |
| --- | --- | --- | --- |
| `Y003` | `-2` 至 `2` | 更强调独立、坚毅和自主；更少强调服从与宗教信仰 | `-2`、`-1` 是有效值，不是缺失编码。 |
| `I_AUTHORITY` | 通常 `0` 至 `1` | 更少尊重权威 | 变量名中的 `I_` 表示 inverse（反向），不能误读为“权威尊重更高”。 |
| `I_NATIONALISM` | 通常 `0` 至 `1` | 更低的国家自豪感 | 同样是反向指标，不是“民族主义更强”。 |
| `DEFIANCE` | 通常 `0` 至 `1` | 更强的反抗性 | 是 Welzel defiance 子指数。 |
| `SCEPTICISM` | 通常 `0` 至 `1` | 更强的怀疑性 | 不等价于对某一特定政府的不信任。 |
| `AUTONOMY` | 通常 `0` 至 `1` | 更强的自主性 | 是解放价值观中的自主性子指数。 |
| `EQUALITY` | 通常 `0` 至 `1` | 更强的平等取向 | 是解放价值观中的平等子指数。 |
| `I_DEVOUT` | 通常 `0` 至 `1` | 更低的宗教虔诚度 | 是反向虔诚度指标，不能误读为“宗教性更高”。 |

### 连续值示例

```json
{
  "raw_features": {
    "Y003": 1,
    "I_AUTHORITY": 0.0,
    "EQUALITY": 0.69
  },
  "standardized_features": {
    "Y003": 0.80,
    "I_AUTHORITY": -0.75,
    "EQUALITY": 0.45
  }
}
```

这表示：该受访者的自主性指数为 `1`，高于完整 WVS 清洗样本平均水平约 `0.80` 个标准差；反向权威尊重指标为 `0.0`，低于平均水平约 `0.75` 个标准差；平等取向为 `0.69`，略高于平均水平约 `0.45` 个标准差。它不意味着这个人必然支持或反对任何具体危机应对政策。

## 给 LLM 使用的规则

1. 输入档案时，应使用字段的自然语言含义和离散标签，而不是仅发送 `Q273: 1` 一类键值对。
2. 对连续指数，应同时说明量程、数值方向和相对总体位置，例如：“反向权威尊重为 0.0，低于总体平均；数值更高表示较少尊重权威”。
3. 不应把问卷字段直接当作决定性的个人叙事。它们只是形成决策背景的观测特征。
4. 不应从 `N_REGION_WVS` 的数值、名义变量的 z-score，或清洗后的缺失 `0` 中推断含义。
5. 审稿包的参考决策提示会发送 18 个可解释字段的原始值、回答状态和标准化值，并附上固定字段解释；`N_REGION_WVS` 只保留在本地数值档案中，不发送给 LLM。

## 与早期字段说明的差异

本字典以官方 Wave 7 v6.0 为准，覆盖早期项目说明中的错误标签：

- `Q273` 是婚姻状态，不是教育；
- `Q274` 是子女数量，不是收入；
- `Q275` 是教育程度，不是婚姻状态；
- `Q3` 是闲暇时间的重要性，不是健康状态；
- `Q46` 是幸福感，不是社会信任；
- `Q55` 是安全住所匮乏频率，不是政治兴趣；
- `Q57` 是一般社会信任，不是社会活动水平；
- `Y003` 是自主性指数，不是“世俗价值”标签；
- `I_AUTHORITY`、`I_NATIONALISM`、`I_DEVOUT` 都是反向指标。
